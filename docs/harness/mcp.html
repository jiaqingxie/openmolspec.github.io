MCP tools

Connect Spectra Harness to an MCP-compatible agent with the stdio server. Install the MCP extra in the environment used to start the server.

python -m pip install ".[mcp]"
python -m openmolspec.mcp

{
  "mcpServers": {
    "openmolspec": {
      "command": "/path/to/environment/bin/python",
      "args": [
        "-m",
        "openmolspec.mcp"
      ]
    }
  }
}

Tools

Tool

Purpose

Arguments

spectra_tasks

Discover model tasks and spectral channels.

None

spectra_datasets

Read dataset cards.

Optional name

spectra_validate

Check input fields and shapes.

task, inputs, model_settings

spectra_predict

Run a model and return its prediction.

task, inputs, model_settings, repeats

Example tool call

{
  "tool": "spectra_predict",
  "arguments": {
    "task": "nmr.forward.13C",
    "inputs": {
      "smiles": "CCO"
    },
    "repeats": 2,
    "model_settings": {
      "root": "/path/to/models",
      "python": "/path/to/nmr-env/bin/python"
    }
  }
}

The agent reads the predicted shifts from result.records. Use spectra_validate with the same task, inputs and settings before prediction.

{
  "completed": true,
  "result": {
    "records": [
      {
        "smiles": "CCO",
        "nucleus": "13C",
        "atom_indices": [
          0,
          1
        ],
        "prediction_ppm": [
          17.774131774902344,
          57.77375793457031
        ]
      }
    ]
  },
  "repeat_predictions_equal": true
}
