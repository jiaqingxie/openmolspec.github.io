IR and Raman from a molecular geometry

Predict infrared and Raman spectra from atomic coordinates using the openSpec model.

The geometry model predicts the Hessian and dipole/polarizability response tensors. Normal-mode analysis converts these tensors into frequencies and activities, which are broadened onto the spectral grid.

This tutorial loads the saved predictions, explains the input/output fields and evaluates the results. Use the final command to run the model on a new dataset.

import json, sys, io
from pathlib import Path
from IPython.display import display, Markdown, SVG
root = next((p for p in [Path.cwd(), *Path.cwd().parents] if (p / 'openmolspec_bench').is_dir()), None)
if root is None:
    raise RuntimeError('Run from the cloned release repository; see Quick Start')
sys.path.insert(0, str(root / 'scripts'))
from documentation_evidence import load_evidence, compact, recompute, render
from documentation_content import results_table
evidence = load_evidence('vibrational.forward')
print('Task:', evidence['task'])
print('Examples:', len(evidence['examples']))

Task: vibrational.forward
Examples: 2

Inputs and outputs

Field

Meaning

geometry

Element symbols and N×3 Cartesian coordinates in Å, taken from the same Gaussian log as the reference.

checkpoints

openSpec Equiformer-v3 Hessian Hi/Hij and dipole/polarizability derivative weights.

Field

Meaning

IR / Raman

Two normalized intensity arrays on 1024 points spanning 400–4000 cm⁻¹.

spectral error

Channel-wise cosine similarity and intensity MAE against paired computed reference spectra.

Visualize the result

IR and Raman spectra for the displayed molecular geometry.

Compare the prediction with the reference and inspect the returned structures or peak positions. The plot is generated directly from the records loaded above.

import matplotlib.pyplot as plt
for example_index in range(1):
    figure = render('vibrational.forward', evidence, example_index=example_index)
    image = io.StringIO()
    figure.savefig(image, format='svg', metadata={'Date': None})
    display(SVG(image.getvalue()))
    plt.close(figure)

Run the model

Configure the runtime and weights following the task guide. Select this task in the benchmark runner to evaluate your dataset.

python -m openmolspec_bench run --workspace /path/to/OpenMolSpec \
  --tasks vibrational.forward --limit 8 --output results/vibrational-forward.json
