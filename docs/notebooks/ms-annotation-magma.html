MS/MS fragment annotation

Find molecular fragments that explain the measured MS/MS peaks.

MAGMa enumerates fragments of the molecular graph and matches their masses to the measured peaks. Each annotation contains its fragment formula, mass error and atom/bond indices.

This tutorial loads the saved predictions, explains the input/output fields and evaluates the results. Use the final command to run the model on a new dataset.

import json, sys, io
from pathlib import Path
from IPython.display import display, Markdown, SVG
root = next((p for p in [Path.cwd(), *Path.cwd().parents] if (p / 'openmolspec_bench').is_dir()), None)
if root is None:
    raise RuntimeError('Run from the cloned release repository; see Quick Start')
sys.path.insert(0, str(root / 'scripts'))
from documentation_evidence import load_evidence, compact, recompute, render
from documentation_content import results_table
evidence = load_evidence('ms.annotation.magma')
print('Task:', evidence['task'])
print('Examples:', len(evidence['examples']))

Inputs and outputs

Field

Meaning

smiles / peaks

Known structure, measured MS/MS peaks [m/z, relative intensity], and adduct.

ppm_tolerance

Mass tolerance, default 10 ppm; not an NMR chemical-shift tolerance.

Field

Meaning

peak_annotations

Candidate fragments, formulas, mass errors and atom/bond indices on engine_smiles.

interpretation

Candidate fragment structures and matching mass errors.

Inspect the example records below. Long arrays show their length and first values; the downloadable JSON contains the complete arrays.
