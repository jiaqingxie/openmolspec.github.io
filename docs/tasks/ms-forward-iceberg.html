MS/MS prediction with ICEBERG

Predict the fragment masses and intensities of a molecule under specified acquisition conditions.

Independent confirmation

Settings were fixed by five-fold validation on 280 scored structures. All 384 original test structures were excluded from the confirmation sample. On the same 875 scored molecules out of 1,024 additional MassSpecGym structures, mean cosine was 0.5118 before calibration and 0.5175 after calibration. The paired 95% interval for the change was [+0.0018, +0.0096]. The 149 remaining structures were skipped. The released predictor applies the selected calibration for the tested acquisition conditions and structures with up to 40 heavy atoms. Use one CPU thread for confirmation and set author_baseline=True in the SDK to reproduce the original output. Paired comparison

Validation and held-out comparison

ICEBERG was evaluated with 189 combinations of intensity scaling, precursor weighting and retained peak count. Of 384 sampled structures per MassSpecGym split, 280 validation and 327 test structures produced a scored prediction. On those same 327 test structures, mean cosine was 0.5050 for the default and 0.5112 for the validation-selected setting. The paired 95% interval for the difference was [-0.0004, 0.0127]. The original model was retained after this first comparison.

What goes in

Field

Meaning

smiles / adduct

Molecular structure and ion/adduct, e.g. the actual [M+H]+ or [M+Na]+ in the record.

collision_energy / instrument

Collision energy and instrument settings supported by the model.

precursor_mz

Recorded precursor m/z; input conventions follow the author interface.

What comes out

Field

Meaning

predicted_peaks

Pairs of m/z and relative intensity; figures retain the top 100 predicted peaks.

similarity

Cosine/entropy similarity to all observed reference peaks, with skipped records counted.

Model and method

ICEBERG takes the molecular structure, adduct, collision energy and instrument. Its fragment and intensity components produce a numerical MS/MS peak list.

Compare the predicted and measured spectra using cosine and entropy similarity.

Reproduce

Notebook with executed figures · Quick Start

python -m openmolspec_bench run --workspace /path/to/OpenMolSpec \
  --tasks ms.forward.iceberg --limit 8 --output results/ms-forward-iceberg-new.json

Call and adapt this model

from openmolspec.model import MSPredictor
model = MSPredictor(model='iceberg', source='/path/to/ms-pred',
    weights='/path/to/weights', python='/path/to/ms-env/bin/python')
result = model.predict(smiles=smiles, adduct='[M+H]+',
    collision_energy=20., instrument='Orbitrap')

Fine-tune using the author training modules. Build molecule-disjoint splits with structures, acquisition conditions, measured peak intensities and the fragment targets required by the chosen architecture. ICEBERG exposes ms_pred.iceberg.train_gen and ms_pred.iceberg.train_inten; GLACIER exposes ms_pred.glacier.train_joint and contrastive joint training. Inspect each entry’s --help and the released configuration before launching. ICEBERG fragment generation uses binary cross-entropy over valid atom decisions; its intensity module supports cosine or entropy objectives. GLACIER joint/contrastive losses depend on its configuration; preserve the selected variant when reporting fine-tuning.

\[L_{\rm cosine}=1-\frac{\hat s\cdot s}{\|\hat s\|\|s\|}.\]
