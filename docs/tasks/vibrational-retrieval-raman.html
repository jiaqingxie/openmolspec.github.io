Raman spectrum-to-structure retrieval

The 4,096-candidate comparison reports embedding search, top-32 reranking and exhaustive matching, with separate query counts.

Rank a SMILES library using one vibrational spectrum.

Retrieve independent reference spectra and rank candidate fingerprint similarity. The native four-channel model is also evaluated with the other channels masked.

Report query count, library size, Top-1/5 hits and mean reciprocal rank.

Field

Meaning

IR / Raman

1024 intensity samples per visible channel, ordered 400→4000 cm⁻¹, using the checkpoint normalization.

reference library

Known paired spectra and structures, separate from the supplied candidates.

candidate structures

The molecular candidate library to rank.

Field

Meaning

ranking

Candidate identities with similarity or ITM positive-class scores.

recall / MRR

Ranking metrics plus candidate-pool size and source composition.
