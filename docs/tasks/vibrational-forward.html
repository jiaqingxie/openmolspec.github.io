IR and Raman from a molecular geometry

Predict infrared and Raman spectra from atomic coordinates using the openSpec model.

What goes in

Field

Meaning

geometry

Element symbols and N×3 Cartesian coordinates in Å, taken from the same Gaussian log as the reference.

checkpoints

openSpec Equiformer-v3 Hessian Hi/Hij and dipole/polarizability derivative weights.

What comes out

Field

Meaning

IR / Raman

Two normalized intensity arrays on 1024 points spanning 400–4000 cm⁻¹.

spectral error

Channel-wise cosine similarity and intensity MAE against paired computed reference spectra.

Model and method

The geometry model predicts the Hessian and dipole/polarizability response tensors. Normal-mode analysis converts these tensors into frequencies and activities, which are broadened onto the spectral grid.

Compare IR and Raman separately using cosine similarity and intensity MAE.

Reproduce

Notebook with executed figures · Quick Start

python -m openmolspec_bench run --workspace /path/to/OpenMolSpec \
  --tasks vibrational.forward --limit 8 --output results/vibrational-forward-new.json

Call and adapt this model

from openmolspec.benchmark import Benchmark
benchmark = Benchmark(workspace='/path/to/workspace',
    python='/path/to/vibrational-env/bin/python',
    portable_root='/path/to/portable-models')
result = benchmark.run('vibrational.forward',
    output='geometry-to-spectrum-results.json', limit=2)

Adapt the openSpec training implementation with reference geometries, Hessians and response tensors using the same atom ordering, units and mode conventions. Tensor/property losses train the forward model; spectral similarity is a downstream evaluation, not automatically its training loss. Each released direct model trains its selected tensor head; the Hessian/response engine averages Cartesian SmoothL1 terms by the global number of tensor components. Separate checkpoints and target units are retained when reconstructing normal modes.

\[\begin{split}\ell_\beta(r)=\begin{cases}r^2/(2\beta),&|r|<\beta,\\ |r|-\beta/2,&|r|\ge\beta.\end{cases}\end{split}\]
\[L_{\rm tensor}=\sum_{q\in\{H_i,H_{ij},\partial\mu,\partial\alpha\}}\frac1{N_q}\sum_j\ell_1(\hat T_{qj}-T_{qj}).\]
