openmolspec.training.prepare_nmr_training(train, validation, destination)

Prepare train/validation files for NMRTransformer training.

Parameters:

  • train (openmolspec.dataset.SpectraSplit) – Experimental H/C NMR training view with role 'train'.

  • validation (openmolspec.dataset.SpectraSplit) – Validation view with role 'val'. Records contain smiles, formula, h_nmr, c_nmr and a channel mask.

  • destination (str or pathlib.Path) – New directory for the prepared JSONLs and verification files.

Returns:

Directory containing train.jsonl, val.jsonl, summary.json and verification.json.

Return type:

pathlib.Path

Raises:

  • ValueError – If split roles, molecular formulae, nucleus labels or cross-split molecular identities disagree with the training format.

  • FileExistsError – If the destination already exists.

class openmolspec.training.TrainingPlan(data_dir: str | Path, run_dir: str | Path, stage: str = 'align', checkpoint: str | None = None, alignment_checkpoint: str | None = None, python: str = sys.executable, device: str = 'cpu', epochs: int = 10, batch_size: int = 32, learning_rate: float = 0.0001, seed: int = 2026, parameters: dict = field(default_factory=dict))

Training configuration for the NMR dual encoder or molecular generator.

Parameters:

  • data_dir (str or pathlib.Path) – Prepared directory returned by prepare_nmr_training().

  • run_dir (str or pathlib.Path) – New directory for logs, configuration and model checkpoints.

  • stage ({'align', 'generate'}, default 'align') – Dual-encoder alignment or autoregressive SMILES generation.

  • checkpoint (str or None, default None) – Weights used to initialize the selected stage.

  • alignment_checkpoint (str or None, default None) – Spectral/molecular encoder checkpoint used by the generation stage.

  • python (str, default sys.executable) – Interpreter of the training environment.

  • device (str, default 'cpu') – Torch training device.

  • epochs (int, default 10) – Number of training epochs.

  • batch_size (int, default 32) – Number of examples per minibatch, at least two.

  • learning_rate (float, default 0.0001) – Optimizer learning rate.

  • seed (int, default 2026) – Seed for model initialization and data order.

  • parameters (dict, optional) – Stage-specific options. Alignment accepts hidden_size, heads, encoder_layers, decoder_layers, feedforward_size, projection_size, alignment_temperature, input_representation, max_source_tokens, max_val_examples and early_stop_patience. Generation accepts alignment_loss_weight, max_val_batches, generate_examples and beam_size. Both stages accept max_train_batches, shuffle_buffer, drop_h_prob, drop_c_prob, log_every and tqdm.

Examples

>>> plan = TrainingPlan('prepared-nmr', 'runs/encoder',
...     epochs=20, batch_size=64, device='cuda:0')
>>> settings = plan.describe()
>>> validation = plan.validate()
>>> result = plan.run()
