openmolspec.workflows.manifest_scan.configure_rdkit_logging(show_warnings: bool = False) → None

Keep RDKit diagnostics from corrupting progress output.

Invalid labels and canonicalization failures are retained in the manifest audit table. The high-volume RDKit warning stream is therefore hidden by default, while errors remain visible. Set show_warnings when investigating a particular label.

openmolspec.workflows.manifest_scan.normalize_peptide_sequence(source: str) → Dict[str, str | None]

Build a standard or modified peptide from a hyphen-delimited ID.

p* residues carry phosphate and s* residues carry sulfate. The modification is attached to the named atom in the corresponding residue, preserving the peptide bonds and stereochemistry created by RDKit.

openmolspec.workflows.manifest_scan.collect_collection(root: Path, dataset: str, *, nmr: bool = False, hash_files: bool = True, label_fallback_dirs: Iterable[Path] = (), workers: int = 1, cache_path: Path | None = None, incremental: bool = True, min_file_age_seconds: float = 0.0, identity_lookup: Dict[str, Dict[str, Any]] | None = None, audit_all_records: bool = True) → Tuple[List[Dict[str, Any]], List[Dict[str, Any]]]

Collect one frequency/property or NMR collection.

Collection shards are reused when path, size, mtime, label metadata and cache schema are unchanged. identity_lookup lets NMR records reuse the already-normalized frequency identity, which is also required for peptide collections whose sequence is encoded in the filename.
