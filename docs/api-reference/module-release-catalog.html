openmolspec.release.catalog.build_catalog(config: Mapping[str, Any], *, manifest_path: str | None = None, frequency_report_path: str | None = None, nmr_report_path: str | None = None) → Dict[str, Any]

Create record, full-molecule and strict-align Parquet tables.

full is molecular-identity unique. It retains independent sample IDs for the best frequency and NMR records. align is a subset whose modalities coexist on one source record, preventing accidental cross-conformer pairing.
