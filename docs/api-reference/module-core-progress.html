Module constant or schema value.
openmolspec.core.progress.progress_mode(stream: TextIO | None = None) → str

Return bar, log or off for the current process.

OPENSPEC_PROGRESS can force one of those modes. The default auto uses a bar only when the output stream is an interactive terminal.
