openmolspec.split.scaffold_group_id(scaffold)

Generate a connectivity-based key for a molecular scaffold.

Parameters:

scaffold (str) – Scaffold SMILES or a 14-letter standard InChIKey connectivity block. The optional prefix 'scaffold:' is accepted.

Returns:

'scaffold:' followed by the normalized connectivity block.

Return type:

str

Raises:

ValueError – If the scaffold cannot be assigned a standard molecular identity.

openmolspec.split.molecular_group(smiles, method='scaffold')

Assign a standard molecular identity and a split-group key.

Parameters:

  • smiles (str) – Molecular structure to group.

  • method ({'scaffold', 'random'}, default 'scaffold') – Scaffold grouping uses an achiral Bemis–Murcko scaffold after standard InChI normalization. Random grouping uses molecular connectivity.

Returns:

Full standard InChIKey, group key and parsed input molecule. Acyclic molecules use connectivity as their scaffold-group fallback.

Return type:

tuple of (str, str, rdkit.Chem.Mol)

Raises:

ValueError – If the structure, identity conversion or grouping method is invalid.

openmolspec.split.split_records(records, destination, *, method='scaffold', seed=2026, ratios=(0.8, 0.1, 0.1), source='user_supplied', domain='experimental')

Export deterministic grouped training, validation and test files.

Parameters:

  • records (iterable of dict) – Spectroscopy records containing smiles or kekule_smiles. Other molecular, spectral and acquisition fields are preserved.

  • destination (str or pathlib.Path) – New directory for three JSONL files and split-manifest.json.

  • method ({'scaffold', 'random'}, default 'scaffold') – Group molecules by achiral normalized scaffold or connectivity.

  • seed (int, default 2026) – Seed incorporated into the deterministic SHA-256 group assignment.

  • ratios (tuple of float, default (0.8, 0.1, 0.1)) – Training, validation and test proportions; nonnegative and summing to one. Complete groups are assigned together, so row counts vary.

  • source (str, default 'user_supplied') – Data-source label written to the manifest.

  • domain ({'experimental', 'computed'}, default 'experimental') – Origin of the spectra written to the manifest.

Returns:

Manifest with per-file counts and SHA-256 values, grouping policy, source fingerprint, requested ratios, seed and original split counts.

Return type:

dict

Raises:

  • FileExistsError – If the destination already exists.

  • ValueError – If records or settings are invalid, or one connectivity receives conflicting scaffold roles. Exports are staged before publication.

Examples

>>> manifest = split_records(records, 'my-data', method='scaffold', seed=42)
>>> manifest['groups_disjoint']
True
