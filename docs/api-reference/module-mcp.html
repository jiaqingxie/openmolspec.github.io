openmolspec.mcp.create_server()

Create the OpenMolSpec MCP server and register its spectroscopy tools.

Returns:

Server exposing spectra_tasks, spectra_datasets, spectra_validate and spectra_predict. Prediction and validation tools take task, inputs and model_settings; prediction also accepts repeats.

Return type:

mcp.server.MCPServer

Raises:

RuntimeError – If the optional MCP dependency is absent.

Examples

>>> server = create_server()
>>> server.run(transport='stdio')
