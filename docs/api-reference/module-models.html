class openmolspec.model.NMRNet(*, models_root, nucleus='13C', python=None, device='cpu')

Predict atomwise H/C chemical shifts and assign NMR peaks.

Parameters:

  • models_root (str or pathlib.Path) – Directory containing nmrnet/nmrnet-orig and nmrnet/weights.

  • nucleus ({'1H', '13C'}, default '13C') – Nucleus to predict with the liquid-state fold-0 checkpoint and scaler.

  • python (str or None, default None) – Interpreter of the NMR model environment. None selects the current Python interpreter.

  • device ({'cpu'}, default 'cpu') – Device used by the NMRNet runtime adapter.

Examples

>>> model = NMRNet.from_pretrained('models', nucleus='13C',
...     python='/path/to/nmr-env/bin/python')
>>> prediction = model.predict('CCO')
>>> shifts = prediction['records'][0]['prediction_ppm']

Atom indices follow the zero-based RDKit AddHs graph of the input SMILES.

assign(smiles, peaks_ppm, *, tolerance_ppm=None)

Match measured peak positions to predicted atomic environments.

Parameters:

  • peaks_ppm (iterable of float) – Measured chemical shifts in ppm, in the desired peak-index order.

  • tolerance_ppm (float or None, default None) – Maximum peak/site residual. The default is 0.5 ppm for H and 5 ppm for C.

Returns:

class openmolspec.model.NMRTransformer(*, checkpoint=None, stage='generate', python=None, device='cpu')

Retrieve and generate molecular structures from experimental NMR.

Parameters:

  • checkpoint (str or pathlib.Path or None, default None) – Alignment or generation checkpoint for prediction or initialization.

  • stage ({'align', 'generate'}, default 'generate') – 'align' selects the dual encoder; 'generate' selects the molecular decoder. The stage also determines the training plan.

  • python (str or None, default None) – Interpreter containing the NMR Transformer dependencies.

  • device (str, default 'cpu') – Torch device, for example 'cpu' or 'cuda:0'.

Examples

>>> model = NMRTransformer.from_pretrained('alignment.pt', stage='align')
>>> ranking = model.retrieve(query, ['CCO', 'COC'], top_k=2)

class openmolspec.model.GapModel(*, root, python=None, device='cpu')

Predict the HOMO–LUMO energy gap from molecular spectra.

Parameters:

  • root (str or pathlib.Path) – openSpec model-assets directory.

  • python (str or None, default None) – Interpreter containing the openSpec model dependencies.

  • device (str, default 'cpu') – Torch device used for inference.

Examples

>>> model = GapModel(root='models/openspec', python='/path/to/model/python')
>>> result = model.predict(inputs)
>>> gap_ev = result['gap_ev']

Source code

predict(inputs, *, top_k=10, allow_missing_modalities=False, ranking='beam', estimate_missing_nmr=True)

Generate molecular structures from IR, Raman and NMR spectra.

Parameters:

  • inputs (dict) – Spectral arrays with keys ir, raman, nmr_h and nmr_c; see GapModel.predict() for their units and shapes.

  • top_k (int, default 10) – Number of candidates to return, between 1 and 10.

  • allow_missing_modalities (bool, default False) – Permit additional missing-channel ablations.

  • estimate_missing_nmr (bool, default True) – With only IR and Raman, estimate chemical shifts from the two spectra before decoding. The result includes the estimated shifts in ppm. Combine False with allow_missing_modalities=True for the unadapted decoder.

Returns:

Canonical candidate structures, decoding/matching scores and checkpoint metadata. The decoder ranks canonical valid beams by default. Pass ranking=”itm” to rank by the matching model instead.

Return type:

dict

predict_native(inputs, *, formula, checkout, top_k=10)

Generate with Xinyu Lu’s VB-Mols IR+Raman checkpoint and a supplied formula.

The checkout must contain the author’s model code, tokenizers and released MMM generation weights under checkpoints/mols. Supply 1024 points per channel on the 400–4000 cm⁻¹ grid. Results include decoded order and formula agreement for each valid candidate.

Source code

retrieve(inputs, candidates, *, top_k=10, rerank=False, allow_missing_modalities=False, estimate_missing_nmr=False, shortlist=None)

Rank a supplied molecular library against a spectral query.

Parameters:

  • inputs (dict) – IR/Raman intensity arrays and H/C shift arrays.

  • candidates (iterable of str) – Candidate structures as SMILES.

  • top_k (int, default 10) – Number of ranked structures to return.

  • rerank (bool, default False) – Use the ITM matching head when True; otherwise use embedding cosine similarity.

  • allow_missing_modalities (bool, default False) – Enable inference with selected channels omitted.

  • estimate_missing_nmr (bool, default False) – Estimate H/C shifts from measured IR and Raman with the fitted adapter.

  • shortlist (int or None) – Apply ITM to this many embedding-ranked candidates. With None, score the full supplied library.

Returns:

candidate_pool, ranking method, and candidates with SMILES and their scores in descending order.

Return type:

dict

class openmolspec.model.MSPredictor(*, model, source, weights, python=None, device='cpu', author_baseline=False)

Predict tandem mass spectra with GLACIER or ICEBERG.

Parameters:

  • model ({'glacier', 'iceberg'}) – Spectrum-prediction architecture.

  • source (str or pathlib.Path) – Directory containing the ms-pred implementation.

  • weights (str or pathlib.Path) – Checkpoint or checkpoint directory for the selected architecture.

  • python (str or None, default None) – Interpreter of the MS model environment.

  • device (str, default 'cpu') – Inference device.

  • author_baseline (bool, default False) – Return the original checkpoint intensities for comparison.

Source code

predict(*, smiles, adduct, collision_energy, instrument, precursor_mz=None)

Predict fragment m/z values and relative intensities.

Parameters:

  • adduct (str) – Ion type, for example '[M+H]+' or '[M+Na]+'.

  • collision_energy (float) – Collision energy in the checkpoint’s acquisition convention.

  • instrument (str) – Instrument category, for example 'Orbitrap' or 'QTOF'.

  • precursor_mz (float or None, default None) – Measured precursor mass-to-charge ratio when available.

Returns:

Numerical predicted MS/MS peaks and the acquisition/model metadata.
