Load a dataset

from openmolspec.dataset import molspectra

data = molspectra("opendatalab_nmr", root="data/nmr")
record = data["test"].head(1)[0]
print(record["smiles"])
print(record["h_peaks_ppm"])
paired = data["train"].select(modalities=["1H", "13C"])

Place the cleaned train.jsonl, val.jsonl and test.jsonl files in data/nmr. The NMR guide explains every field and the split guide explains how to construct your own dataset. Download counts and distributions.
