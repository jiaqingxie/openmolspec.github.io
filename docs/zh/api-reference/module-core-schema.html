class openmolspec.core.schema.FieldSpec(dtype: str, shape: str, unit: str | None, missing_value_policy: str, description: str, required: bool = False)

Describe one field in the OpenSpec molecular record schema.

参数:

  • dtype (str) -- Logical storage type, such as 'float32' or 'string'.

  • shape (str) -- Scalar or array dimensions, including symbolic atom count N.

  • unit (str or None) -- Physical unit; None denotes a unitless metadata field.

  • missing_value_policy (str) -- Representation of an unavailable value and its associated flags.

  • description (str) -- Meaning of the field for a molecular record.

  • required (bool, default False) -- Whether the field name must be present in a conforming record.
