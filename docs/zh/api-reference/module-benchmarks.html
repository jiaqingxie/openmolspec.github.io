class openmolspec.benchmark.Benchmark(*, workspace, python=None, **assets)

Run spectroscopy benchmark tasks with configured model and data assets.

参数:

  • workspace (str or pathlib.Path) -- Workspace containing the prepared evaluation datasets.

  • python (str or None, default None) -- Interpreter used to launch the benchmark command.

  • **assets -- Model/data locations accepted by the benchmark CLI: models_root, portable_root, alignment_checkpoint, generation_checkpoint, transpeaknet_source, nmr_python, ms_python, solvent_library, ms_source, ms_weights, ms_input_csv, ms_metadata_tsv, magma_source, gap_lmdb, fp_inference_root and solution_shift_root.

Examples

>>> benchmark = Benchmark(workspace='data', models_root='models')
>>> results = benchmark.run('nmr.forward.13C',
...     output='results/carbon.json', limit=32)

run(tasks, *, output, datasets=None, limit=32, seed=42, sampling='reservoir', device='cpu', allow_cross_domain_diagnostic=False, solution_reference='test')

Evaluate selected tasks and save their predictions and metrics.

参数:

  • tasks (str or iterable of str) -- Task IDs returned by openmolspec.task.list_tasks.

  • output (str or pathlib.Path) -- New JSON results file to create.

  • datasets (str or iterable of str or None, default None) -- Prepared dataset views to evaluate.

  • limit (int, default 32) -- Maximum number of selected examples per task/data view.

  • seed (int, default 42) -- Seed used for example selection.

  • sampling ({'reservoir', 'first'}, default 'reservoir') -- Reservoir sampling or source-file order.

  • device (str, default 'cpu') -- Model runtime device.

  • allow_cross_domain_diagnostic (bool, default False) -- Enable the F/P comparison of solid-state model predictions with solution-reference records. The result retains both domain labels.

  • solution_reference ({"test", "historical-pool"}, default "test") -- Reference set for the fitted 19F and 31P solution models.

返回:

Saved result object with task IDs, metrics, sample information, predictions and model/data fingerprints.

返回类型:

dict

抛出:

  • FileExistsError -- If the output file already exists.

  • ValueError -- If task IDs or sampling options are invalid.

Compare predicted NMR peaks with measured peak lists.

参数:

  • prediction (dict) -- NMRNet prediction containing records[*].prediction_ppm.

  • references (iterable of iterable of float) -- One reference peak list per prediction record, in ppm.

返回:

Peak-matching MAE/RMSE, matched coverage and peak-count statistics.

返回类型:
