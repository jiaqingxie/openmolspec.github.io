class openmolspec.dataset.SpectraSplit(path: Path, role: str, dataset: str, domain: str, format: str = 'nmr_jsonl', trusted: bool = False, modalities: tuple[str, ...] = (), limit: int | None = None)

A streaming view of one spectroscopy dataset split.

参数:

  • path (str or pathlib.Path) -- JSONL, MassSpecGym CSV/TSV, openSpec LMDB, or TransPeakNet test ZIP file.

  • role ({'train', 'val', 'test'}) -- Split to read. 'valid' and 'validation' are aliases for 'val'.

  • dataset (str) -- Dataset name attached to each returned record.

  • domain ({'experimental', 'computed'}) -- Origin of the spectral measurements.

  • format (str, default 'nmr_jsonl') -- Reader format: 'nmr_jsonl', 'jsonl', 'massspecgym_csv', 'massspecgym_tsv', 'openspec_lmdb' or 'transpeaknet_hsqc_zip'.

  • trusted (bool, default False) -- Set to True when opening a trusted pickle-based LMDB.

  • modalities (tuple of str, default ()) -- Channels required in each selected record: '1H', '13C', '11B', '19F', '29Si', '31P', 'IR', 'Raman', 'MS', 'MS/MS' or 'HSQC'.

  • limit (int or None, default None) -- Maximum number of selected records.

Yields:

dict -- Molecular and spectral fields plus _openmolspec metadata containing the split, dataset, domain, record locator and available channels.

Examples

>>> split = SpectraSplit('test.jsonl', 'test', 'my_nmr', 'experimental')
>>> first_three = split.head(3)
>>> hc = split.select(modalities=['1H', '13C'], limit=32)

class openmolspec.dataset.MolecularSpectra(card, splits)

A dataset card together with its train, validation and test views.

参数:

  • card (dict) -- Dataset metadata, including the name, version and source information.

  • splits (mapping of str to SpectraSplit) -- Named split views, indexed by 'train', 'val' and 'test'.

Examples

>>> data = molspectra('opendatalab_nmr', root='data/nmr')
>>> test = data['test']
>>> record = test.head(1)[0]
>>> print(record['smiles'])

classmethod from_jsonl(*, splits, name, domain, format='nmr_jsonl')

Create a dataset from your own JSONL files.

参数:

  • splits (mapping of str to path-like) -- JSONL files keyed by split, for example {'train': 'train.jsonl', 'val': 'val.jsonl'}.

  • name (str) -- Name to attach to returned records.

  • domain ({'experimental', 'computed'}) -- Spectral data origin.

  • format ({'nmr_jsonl', 'jsonl'}, default 'nmr_jsonl') -- Use 'nmr_jsonl' for H/C peak-text records and 'jsonl' for general molecular/spectral dictionaries.

返回:

Dataset with the supplied split files.

返回类型:

MolecularSpectra

Examples

>>> custom = MolecularSpectra.from_jsonl(
...     splits={'train': 'train.jsonl', 'val': 'val.jsonl'},
...     name='my_measurements', domain='experimental')

openmolspec.dataset.molspectra(name, *, root, trusted=False)

Load a registered molecular spectroscopy dataset.

参数:

  • name (str) -- Name returned by list_datasets().

  • root (str or pathlib.Path) -- Directory containing the dataset card's split files. Single-file datasets also accept the file path directly.

  • trusted (bool, default False) -- Enable the reader for a trusted pickle-based LMDB.

返回:

Dataset with lazy split readers.

返回类型:

MolecularSpectra

抛出:

  • FileNotFoundError -- If no expected split file exists under root.

  • ValueError -- If name is unknown.

Examples

>>> data = molspectra('opendatalab_nmr', root='data/nmr')
>>> records = data['test'].select(modalities=['1H', '13C']).head(3)

openmolspec.dataset.audit_splits(splits, *, identity='connectivity', check_nmr=False)

Scan supplied views for molecular overlap using a disk-backed identity index.

参数:

  • splits (mapping of str to iterable of dict) -- Named molecular record streams, usually data.get_split().

  • identity ({'connectivity', 'inchi'}, default 'connectivity') -- Compare the connectivity block or the full standard InChIKey. Connectivity grouping keeps stereoisomers together.

  • check_nmr (bool, default False) -- Validate each record's H/C peak representation while scanning.

返回:

Record and unique-identity counts, repeated identities, cross-split overlaps and molecular-identity policy. Standard InChIKeys are recomputed from SMILES.

返回类型:

dict

Examples

>>> report = audit_splits(data.get_split(), identity='connectivity')
