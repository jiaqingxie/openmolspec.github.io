openmolspec.release.common.load_config(path: str | Path) → Dict[str, Any]

Read a YAML release configuration.

参数:

path (str or pathlib.Path) -- YAML file containing a release mapping.

返回:

Parsed configuration with its absolute path in _config_path.

返回类型:

dict

抛出:

ValueError -- If the YAML document is not a release configuration mapping.

Source code

openmolspec.release.common.resolve_path(config: Mapping[str, Any], value: str | Path) → Path

Resolve a release path relative to its repository.

参数:

  • config (mapping) -- Configuration returned by load_config().

  • value (str or pathlib.Path) -- Absolute path or path relative to the parent of the config directory.

返回:

Resolved release input or output path.

返回类型:

pathlib.Path

openmolspec.release.common.atomic_json(path: Path, payload: Any) → None

Write JSON through a temporary file and atomically replace its destination.

参数:

  • path (pathlib.Path) -- JSON destination; parent directories are created as needed.

  • payload (object) -- JSON-compatible data, with NumPy and path values converted by json_default().

返回:

Writes an indented UTF-8 JSON file.

返回类型:

None

Source code

openmolspec.release.common.json_default(value: Any) → Any

Convert path and NumPy values for JSON encoding.

参数:

value (object) -- A path, NumPy scalar or NumPy array.

返回:

JSON-compatible representation.

返回类型:

str, number or list

抛出:

TypeError -- If the object has no supported conversion.

Source code

openmolspec.release.common.stable_digest(value: str, seed: int = 0) → str

Hash a value with a deterministic seed prefix.

参数:

  • value (str) -- Identifier to hash.

  • seed (int, default 0) -- Namespace seed prepended to the identifier.

返回:

SHA-256 hexadecimal digest of f'{seed}:{value}'.

返回类型:

str

Compute a file checksum using bounded-memory reads.

  • block_size (int, default 16777216) -- Bytes read per iteration.

str
