Description

openmolspec.task.list_tasks()

List the spectroscopy tasks and their model/evaluation interfaces.
openmolspec.task.list_tasks(*, group=None, include_deferred=False)

List the spectroscopy tasks and their model/evaluation interfaces.

参数:

  • group ({'nmr', 'ms', 'vibrational', 'multimodal', 'deferred'} or None) -- Select one task family. None returns all enabled families.

  • include_deferred (bool, default False) -- Include the additional task definitions outside the active suite.

返回:

Task ID, title, spectral channels, domain, backend, metrics and group.

返回类型:

list of dict

Examples

>>> nmr = list_tasks(group='nmr')
>>> all(task['id'].startswith('nmr.') for task in nmr)
True
