class openmolspec.harness.HarnessPlugin(name: str, task_ids: tuple, validate: object, execute: object)

Backend functions for a family of spectroscopy tasks.

参数:

  • name (str) -- Display name of the model family.

  • task_ids (tuple of str) -- Task identifiers served by this plugin.

  • validate (callable) -- validate(task, inputs, model_config) checks the request and raises ValueError for invalid fields.

  • execute (callable) -- execute(task, inputs, model_config) runs the model and returns a JSON-serializable prediction dictionary.

class openmolspec.harness.SpectraHarness(plugins=None)

Discover, validate and run spectroscopy model tasks.

参数:

plugins (iterable of HarnessPlugin or None, default None) -- Model plugins to register. None installs the NMR, MS and vibrational plugins returned by default_plugins().

Examples

>>> harness = SpectraHarness()
>>> tasks = harness.catalog()
>>> inputs = {'smiles': 'CCO'}
>>> settings = {'root': 'models', 'python': '/path/to/nmr-env/bin/python'}
>>> harness.validate('nmr.forward.13C', inputs, settings)['valid']
True

validate(task, inputs, model_config)

Check task fields and spectral array shapes.

参数:

  • task (str) -- Registered task identifier.

  • inputs (dict) -- Molecular or spectral fields expected by the selected task.

  • model_config (dict) -- Model paths and runtime settings. NMR uses root or checkpoint; MS uses source and weights; vibrational models use root. python selects the model environment.

返回:

valid=True, task identifier and plugin family.

返回类型:

dict

抛出:

ValueError -- If a task or required request field is invalid.

Source code

run(task, inputs, model_config, *, repeats=1)

Run a model request and return its prediction and call history.

参数:

  • task (str) -- Model task from catalog().

  • inputs (dict) -- Task inputs, using the same fields as validate().

  • model_config (dict) -- Model and interpreter paths for the selected plugin.

  • repeats (int, default 1) -- Number of identical calls, from 1 to 5.

返回:

completed, result, calls, prediction/output hashes and repeat equality fields. For repeated requests, repeat_results contains the individual outputs. Each call records elapsed seconds, status and, on failure, its error type and message.

返回类型:

dict

openmolspec.harness.main()

Run the spectra-harness command-line interface.

Commands are catalog, validate --request request.json and run --request request.json --output result.json. Request files contain task, inputs, model_config and optional repeats.
