由 IR + Raman 预测 HOMO–LUMO 能隙

能隙评测收录了 1,024 条四谱输入和 3,381 条缺通道模型的结果。

根据谱图估计分子的 HOMO–LUMO 能隙。

仅用振动谱的回归模型

输入 IR + Raman 且没有 NMR 时，软件使用专门训练的谱到能隙回归模型。在 OpenMolSpec 理论谱上重新按连通结构划分，训练 11,568 种分子，验证 1,651 种，测试 3,381 种。测试 MAE 为 0.288 eV，训练均值对照为 0.749 eV。历史 128 个查询单独留出，回测 MAE 为 0.304 eV。下方原始图表记录四通道模型屏蔽输入后的表现。

输入是什么

Field

Meaning

IR / Raman

每个可见通道 1024 个强度点，按 400→4000 cm⁻¹ 排列，并采用 checkpoint 的归一化。

model selection

根据提供的振动谱通道选择相应的能隙回归模型。

输出是什么

Field

Meaning

gap_ev

一个 HOMO–LUMO gap 预测值（eV）；原始 Hartree 标签仅转换一次。

MAE / baseline

与参考值的误差，以及相同样本上固定训练均值基线的误差。

模型与方法

岭回归模型使用合并频段后的振动谱强度及与参考谱的相似度。软件根据输入通道选择模型，输出单位为 eV。

报告以 eV 为单位的 MAE 与 RMSE。

复现方式

Notebook with executed figures · Quick Start

python -m openmolspec_bench run --workspace /path/to/OpenMolSpec \
  --tasks vibrational.gap.ir_raman --limit 8 --output results/vibrational-gap-ir_raman-new.json

调用模型与微调

from openmolspec.model import GapModel
model = GapModel(root='/path/to/portable-models',
    python='/path/to/vibrational-env/bin/python')
result = model.predict(inputs, allow_missing_modalities=True)

通过 openSpec／Vib2Mol 作者训练流程进行适配。准备谱—结构对齐的 LMDB，保留 H/C 参考和归一化，确保 train/val 分组独立。检索采用双向对比交叉熵与配对分类交叉熵；生成使用分子 token 自回归交叉熵。性质回归按其训练配置保留目标变换和回归准则。SDK 提供推理，相关训练通过作者实现执行。 当前 Vib2Conf 性质引擎对训练集标准化目标使用平均 SmoothL1；beta 为正数，默认 1。验证与推理使用相同的训练均值和标准差。

\[\begin{split}\ell_\beta(r)=\begin{cases}r^2/(2\beta),&|r|<\beta,\\ |r|-\beta/2,&|r|\ge\beta.\end{cases}\end{split}\]
\[L_{\rm gap}=\frac1N\sum_i\ell_\beta\left(\hat z_i-\frac{y_i-\mu_{\rm train}}{\sigma_{\rm train}}\right).\]
