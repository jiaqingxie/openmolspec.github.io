29Si 化学位移预测

根据分子结构预测 29Si 化学位移。利用返回的原子编号，可以把预测值标到分子结构上，也可以与实测峰比较。

输入是什么

Field

Meaning

smiles / geometry

有效分子结构及相容的三维构象，必须保留原子顺序。

nucleus

29Si，权重必须覆盖该核种。

reference peaks

评测时提供实测 ppm 标签；标签不作为模型推理输入。

输出是什么

Field

Meaning

prediction_ppm

逐原子化学位移（ppm）及原子编号，或整理后的峰列表。

error / coverage

与参考谱匹配后的误差及峰覆盖率。

模型与方法

NMRNet 编码分子构象，并预测所选原子的化学位移。接口负责准备构象、加载相应核种的权重，并应用模型的位移缩放参数。

MAE 和 RMSE 的单位均为 ppm。

复现方式

Notebook with executed figures · Quick Start

python -m openmolspec_bench run --workspace /path/to/OpenMolSpec \
  --tasks nmr.forward.29Si --limit 8 --output results/nmr-forward-29Si-new.json

调用模型与微调

from openmolspec.benchmark import Benchmark
benchmark = Benchmark(workspace='/path/to/workspace',
    python='/path/to/sdk-env/bin/python',
    models_root='/path/to/models',
    nmr_python='/path/to/nmr-env/bin/python')
result = benchmark.run('nmr.forward.29Si', output='29Si-results.json', limit=32)

微调使用 NMRNet 作者训练实现：准备对应核种的逐原子标签、结构／坐标、目标掩码及 train/val LMDB。实现提供 atom_regloss_mae 与 atom_regloss_mse，在有标签的原子上计算目标。保留 scaler 和参考标准，在验证集选择 checkpoint。该训练流程通过作者实现运行。

\[L_{\rm MAE}=\frac{1}{N_{\rm labelled}}\sum_{i\in\mathcal M}|\hat\delta_i-\delta_i|,\qquad L_{\rm MSE}=\frac{1}{N_{\rm labelled}}\sum_{i\in\mathcal M}(\hat\delta_i-\delta_i)^2.\]
