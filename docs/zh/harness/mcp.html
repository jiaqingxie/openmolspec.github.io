MCP tools

通过 stdio 服务，可以把 Spectra Harness 接入支持 MCP 的 Agent。先在启动服务的环境中安装 MCP 扩展。

python -m pip install ".[mcp]"
python -m openmolspec.mcp

{
  "mcpServers": {
    "openmolspec": {
      "command": "/path/to/environment/bin/python",
      "args": [
        "-m",
        "openmolspec.mcp"
      ]
    }
  }
}

Tools

Tool

Purpose

Arguments

spectra_tasks

Discover model tasks and spectral channels.

None

spectra_datasets

Read dataset cards.

Optional name

spectra_validate

Check input fields and shapes.

task, inputs, model_settings

spectra_predict

Run a model and return its prediction.

task, inputs, model_settings, repeats

工具调用示例

{
  "tool": "spectra_predict",
  "arguments": {
    "task": "nmr.forward.13C",
    "inputs": {
      "smiles": "CCO"
    },
    "repeats": 2,
    "model_settings": {
      "root": "/path/to/models",
      "python": "/path/to/nmr-env/bin/python"
    }
  }
}

Agent 从 result.records 读取预测位移。预测前，使用相同的任务、输入和设置调用 spectra_validate。

{
  "completed": true,
  "result": {
    "records": [
      {
        "smiles": "CCO",
        "nucleus": "13C",
        "atom_indices": [
          0,
          1
        ],
        "prediction_ppm": [
          17.774131774902344,
          57.77375793457031
        ]
      }
    ]
  },
  "repeat_predictions_equal": true
}
