## NMR 峰位余弦相似度

将预测和参考峰表中的每个峰都表示为单位面积的洛伦兹峰，在整个 ppm 轴上计算两条曲线的余弦相似度。所有峰都参与积分，包括多报或漏报的峰。该分数衡量峰位重合程度。实测峰强、多重峰裂分及线形未纳入评分。HSQC 在碳、氢两个维度同时计算，每张专家标注谱等权。

| 任务 | 留出结构或谱数 | 基准半高全宽（ppm） | 0.5 倍宽度 | 基准宽度 | 2 倍宽度 |
| --- | ---: | --- | ---: | ---: | ---: |
| ¹H | 2,971 | 0.05 | 0.2775 | **0.4385** | 0.6127 |
| ¹³C | 2,728 | 1 | 0.6499 | **0.7829** | 0.8806 |
| ³¹P | 4,248 | 1 | 0.3211 | **0.4623** | 0.6085 |
| ¹⁹F | 14,330 | 1 | 0.5020 | **0.6374** | 0.7590 |
| ¹¹B | 1,517 | 1 | 0.5623 | **0.7185** | 0.8358 |
| ²⁹Si | 177 | 1 | 0.3394 | **0.5142** | 0.6960 |
| HSQC (¹³C, ¹H) | 479 | 1 / 0.05 | 0.0822 | **0.2115** | 0.4347 |

¹H、¹³C 合并三个留出集后按分子等权。按 NMRSpec、NMRExp、NMRGym 单列，¹H 为 0.4417 / 0.4364 / 0.4373，¹³C 为 0.8568 / 0.8716 / 0.6397。³¹P、¹⁹F、¹¹B 和 ²⁹Si 的参考记录各只有一个化学环境。先在同一结构内对各次测量取平均，再对结构取平均。谱宽是本次评测设定，HSQC 两轴的宽度同时缩放。IR、拉曼和 MS/MS 的强度谱余弦见上表。[完整精度、分数据集结果与来源校验值](https://github.com/jiaqingxie/openmolspec-studio-frontend/blob/release/openmolspec-v1/results/forward_cosine_similarity.json)

## 评测指标

回归任务以目标单位报告 MAE 与 RMSE；检索报告给定候选池上的 Recall@k 和平均倒数排名；结构生成报告规范化结构 top-k 准确率及有效 SMILES 比例；谱预测使用余弦和熵相似度比较数值强度。

$$\mathrm{MAE}=\frac1N\sum_{i=1}^{N}|\hat y_i-y_i|,\qquad \mathrm{RMSE}=\sqrt{\frac1N\sum_{i=1}^{N}(\hat y_i-y_i)^2}.$$

$$\mathrm{Recall@}k=\frac1N\sum_i\mathbf{1}[r_i\leq k],\qquad \mathrm{MRR}=\frac1N\sum_i\frac1{r_i}.$$

## 运行评测

```bash
python -m openmolspec_bench list
python -m openmolspec_bench run --workspace /path/to/OpenMolSpec \
  --tasks nmr.retrieval.hc.s2m nmr.generation.hc \
  --alignment-checkpoint /path/to/alignment.pt \
  --generation-checkpoint /path/to/generation.pt \
  --limit 64 --sampling reservoir --seed 42 --output results/nmr.json
```

按任务指南指定所需模型文件。结果 JSON 保存预测、目标值、数据设置、指标与模型指纹。
