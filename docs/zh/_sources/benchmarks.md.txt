OpenMolSpec 为 NMR、质谱、振动光谱与多谱联合定义了基准任务。本目录列出全部活跃任务、保存的评测结果，以及训练实验配置。

下表涵盖 10 个已启用的正向配置，³¹P 和 ¹⁹F 按完整留出集报告。各任务页列出参考数据、模型选择方法和推理入口。

¹H、¹³C 按 NMRSpec、NMRExp、NMRGym 顺序列出分子等权的峰集误差。漏峰或多峰每个按 1 ppm（H）或 10 ppm（C）计分。其余一维核磁依次列出单环境实测记录的逐观测、逐分子等权 MAE。²⁹Si 留出集只有 177 种结构。历版 NMR 模型沿用了同一批测试分子，导入模型的上游预训练重叠尚未独立核实。

2DNMRGym 中排除作者二维拟合名单重叠后剩 405 张谱，双轴命中率 50.96%。万卷另有 21 张局部峰表，已报告峰命中 35 / 95，局部 cosine 0.0405，69 / 95 得到候选碳。原子指认真值缺失。 [HSQC 任务指南](tasks/nmr-hsqc-transpeaknet.md)

IR 和拉曼以量子化学计算谱为参考，覆盖只含 H/C/N/O/F、至多 9 个重原子的分子。两个 MS 后端在同一个复核样本上评分，可评分的 875 种结构逐一相同。表中分别列出可在支持的采集条件下得到配对预测的分子数与抽样总数。 [逐项结果与评测记录](https://github.com/jiaqingxie/openmolspec-studio-frontend/blob/release/openmolspec-v1/results/forward_benchmark_summary.json)

## NMR 化学位移 R²

³¹P 和 ¹⁹F 的默认测试集分别排除原发布模型绝对位移误差最大的 1% 实测记录（向上取整）。记录编号在抽样前固定，后续模型沿用同一名单。这种按模型误差事后筛选的子集衡量其余记录上的表现，极端记录是否存在标注问题仍待核实。下表按分子等权；源码评测器支持用 `--solution-reference full-test` 复现完整集。 [固定排除名单](https://github.com/jiaqingxie/openmolspec-studio-frontend/blob/release/openmolspec-v1/src/openmolspec/assets/solution-test-exclusions.json)

| 核种 | 保留 / 全部测量 | 固定子集 MAE（ppm） | 完整集 MAE（ppm） | 固定子集 R² | 完整集 R² |
| --- | ---: | ---: | ---: | ---: | ---: |
| ³¹P | 6,626 / 6,693 | 3.625 | 5.538 | 0.9711 | 0.4811 |
| ¹⁹F | 15,644 / 15,803 | 3.233 | 5.622 | 0.8945 | 0.2132 |

同一口径下，完整集 ¹¹B 和 ²⁹Si 的位移 R² 分别为 0.9448、0.9383。

¹H 和 ¹³C 的主结果使用三个完整留出集。在每张谱内，将预测峰与实测峰一对一配对，使绝对位移误差之和最小。匹配峰的 MAE 和 R² 按分子等权，合并 R² 使用全部配对峰的加权均值。覆盖率为每张谱匹配峰数除以预测与实测峰数中的较大值，再对分子取平均。含漏峰、多峰惩罚的峰集误差单独计分，见首表。

| 数据集 | ¹H R² | ¹H 匹配峰 MAE（ppm） | ¹H 覆盖率 | ¹³C R² | ¹³C 匹配峰 MAE（ppm） | ¹³C 覆盖率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| NMRSpec | 0.9228 | 0.298 | 86.7% | 0.9903 | 1.103 | 95.8% |
| NMRExp | 0.9419 | 0.264 | 86.0% | 0.9946 | 0.951 | 96.5% |
| NMRGym | 0.1537 | 0.731 | 78.6% | 0.9876 | 2.508 | 92.9% |
| 全部 | 0.3315 | 0.429 | 83.8% | 0.9905 | 1.566 | 94.9% |

NMRGym 的 ¹H 参考峰含 135.5 和 138.1 ppm 两个值，这些大残差在 R² 中按平方计入。作为敏感性分析，合并三个库后按每张谱的匹配峰 MAE 排序，分别去掉最差的 1% 整谱。¹H 去掉 30 张后，R² 为 0.9433、MAE 为 0.274 ppm；¹³C 去掉 28 张后，R² 为 0.9941、MAE 为 1.422 ppm。 [完整结果与分库统计](https://github.com/jiaqingxie/openmolspec-studio-frontend/blob/release/openmolspec-v1/results/forward_cosine_similarity.json)

## NMR 峰位余弦相似度

将预测和参考峰表中的每个峰都表示为单位面积的洛伦兹峰，在整个 ppm 轴上计算两条曲线的余弦相似度。所有峰都参与积分，包括多报或漏报的峰。该分数衡量峰位重合程度。实测峰强、多重峰裂分及线形未纳入评分。HSQC 在碳、氢两个维度同时计算，每张 2DNMRGym 官方谱等权。

| 任务 | 留出结构或谱数 | 基准半高全宽（ppm） | 0.5 倍宽度 | 基准宽度 | 2 倍宽度 |
| --- | ---: | --- | ---: | ---: | ---: |
| ¹H | 2,971 | 0.05 | 0.2775 | **0.4385** | 0.6127 |
| ¹³C | 2,728 | 1 | 0.6499 | **0.7829** | 0.8806 |
| ³¹P | 4,248 | 1 | 0.3211 | **0.4623** | 0.6085 |
| ¹⁹F | 14,330 | 1 | 0.5020 | **0.6374** | 0.7590 |
| ¹¹B | 1,517 | 1 | 0.5623 | **0.7185** | 0.8358 |
| ²⁹Si | 177 | 1 | 0.3394 | **0.5142** | 0.6960 |
| HSQC (¹³C, ¹H) | 479 | 1 / 0.05 | 0.0817 | **0.2118** | 0.4361 |

¹H、¹³C 合并三个留出集后按分子等权。按 NMRSpec、NMRExp、NMRGym 单列，¹H 为 0.4417 / 0.4364 / 0.4373，¹³C 为 0.8568 / 0.8716 / 0.6397。³¹P、¹⁹F、¹¹B 和 ²⁹Si 的参考记录各只有一个化学环境。先在同一结构内对各次测量取平均，再对结构取平均。谱宽是本次评测设定，HSQC 两轴的宽度同时缩放。IR、拉曼和 MS/MS 的强度谱余弦见上表。[完整精度、分数据集结果与来源校验值](https://github.com/jiaqingxie/openmolspec-studio-frontend/blob/release/openmolspec-v1/results/forward_cosine_similarity.json)

## 4,096 个候选结构的检索与重排

128 个查询共用同一候选库，每个真结构都在库中。嵌入检索和前 32 名匹配头重排覆盖全部查询；全库重排对前 32 个查询分别给全部 4,096 个候选打分。目标按忽略立体化学的规范 SMILES 比对，模型输入不含分子式。

| 输入与模型 | 嵌入 Top-1 | 前 32 重排 Top-1 | 全库重排 Top-1 | 全库重排 Top-5 |
| --- | --- | --- | --- | --- |
| IR 单谱，屏蔽其余通道 | 0 / 128 | 0 / 128 | 0 / 32 | 0 / 32 |
| Raman 单谱，屏蔽其余通道 | 0 / 128 | 0 / 128 | 0 / 32 | 0 / 32 |
| IR + Raman，VB-Mols | 0 / 128 | 0 / 128 | 0 / 32 | 1 / 32 |
| IR + Raman，估计 H/C | 41 / 128 | 39 / 128 | 8 / 32 | 13 / 32 |
| IR + Raman + 给定 ¹H + ¹³C | 118 / 128 | 120 / 128 | 31 / 32 | 32 / 32 |

另一条检索路径将查询谱与独立理论参考谱库比较。128 个查询上，第一轮检索的 Top-1 命中数为 IR 27/128, Raman 28/128, IR + Raman 31/128, 四谱 34/128。上表神经模型的候选库仅提供 SMILES。

## 评测指标

回归任务以目标单位报告 MAE 与 RMSE；检索报告给定候选池上的 Recall@k 和平均倒数排名；结构生成报告规范化结构 top-k 准确率及有效 SMILES 比例；谱预测使用余弦和熵相似度比较数值强度。

$$\mathrm{MAE}=\frac1N\sum_{i=1}^{N}|\hat y_i-y_i|,\qquad \mathrm{RMSE}=\sqrt{\frac1N\sum_{i=1}^{N}(\hat y_i-y_i)^2}.$$

$$\mathrm{Recall@}k=\frac1N\sum_i\mathbf{1}[r_i\leq k],\qquad \mathrm{MRR}=\frac1N\sum_i\frac1{r_i}.$$

## 运行评测

```bash
python -m openmolspec_bench list
python -m openmolspec_bench run --workspace /path/to/OpenMolSpec \
  --tasks nmr.retrieval.hc.s2m nmr.generation.hc \
  --alignment-checkpoint /path/to/alignment.pt \
  --generation-checkpoint /path/to/generation.pt \
  --limit 64 --sampling reservoir --seed 42 --output results/nmr.json
```

按任务指南指定所需模型文件。结果 JSON 保存预测、目标值、数据设置、指标与模型指纹。

## 其他任务定义

SpecMol 接收谱学问题和谱文本。SpectraLLM 按规范化 SMILES 评估多谱结构生成。两项均需各自的本地合并权重。独立的分子式预测已停用。
