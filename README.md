# OpenMolSpec v1.0 project site

https://jiaqingxie.github.io/openmolspec.github.io/

Introduction, online tools, experimental dataset previews and a Documentation entry. GitHub Pages serves the static frontend; model requests execute on the separate Python API.
Source: https://github.com/jiaqingxie/openmolspec-studio-frontend/tree/release/openmolspec-v1/website
Deployment: https://github.com/jiaqingxie/openmolspec-studio-frontend/tree/release/openmolspec-v1/online_api

The full bilingual manual is also bundled at docs/. The public API currently uses a temporary demonstration tunnel; permanent hosting requires a stable HTTPS origin and supervised model processes. No provider key is included in this repository.
